# Job Description & Gap Matching

Extract the JD into:
- must-have hard skills
- preferred hard skills
- behavioral/soft skills
- years/level
- education
- domain knowledge
- tools/platforms
- responsibilities
- keywords
- implied competencies

Map each requirement to candidate evidence:
STRONG_EVIDENCE / WEAK_EVIDENCE / NO_EVIDENCE / CONFLICTING_EVIDENCE.

Never tell the user to add a keyword when they do not actually possess the skill. Suggest truthful alternatives:
- move existing evidence earlier
- use the exact term when equivalent
- learn the missing skill
- build a project
- prepare an interview story

Generate a gap-to-action plan and identify which gaps are most likely to matter for the target role.
