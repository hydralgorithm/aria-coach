# Resume Intelligence

## Parsing
Extract into a canonical candidate profile:
- contact fields
- target roles
- summary
- education
- experience
- projects
- skills
- certifications
- achievements
- links

Keep source text and normalized fields so feedback can point back to the exact resume evidence.

## ATS compatibility
Evaluate:
- parseability
- standard section headings
- reading order
- columns/tables/text boxes
- graphics/photos/charts
- unusual symbols
- headers/footers
- dates
- file type
- keyword coverage
- role/title alignment
- achievement specificity

Do not pretend all ATS platforms behave identically. Use "ATS compatibility" or "parser robustness" rather than a fake universal score.

## Rewriting
Turn weak bullets into action + task + technology + measurable outcome only when the evidence exists. If a metric is missing, suggest what evidence would make the bullet stronger rather than inventing a number.

## Output
Produce:
- structured candidate profile
- parse warnings
- strongest evidence
- weak/missing evidence
- rewrite candidates
- unsupported-claim flags
