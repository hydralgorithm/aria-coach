# Adaptive Interview Orchestrator

Interview setup must bind together:
- candidate profile
- resume
- target role
- job description
- interview stage
- selected difficulty
- prior performance gaps

Question mix should be chosen deliberately:
- resume/project deep dive
- behavioral
- role-specific technical
- scenario/problem solving
- recruiter/HR
- company-context questions when source material is available

Rules:
1. Start easy enough to establish baseline.
2. Increase difficulty when answers are strong.
3. Drill deeper when an answer contains a claim worth validating.
4. Re-ask weak concepts later using a different wording.
5. Avoid repetitive generic questions.
6. Keep a clear rubric per question.
7. Do not reveal the ideal answer before the attempt.

A signature capability is "resume claim interrogation":
If the resume says "optimized API latency by 40%", ask how it was measured, what bottleneck was found, what changed, and what trade-off resulted.
