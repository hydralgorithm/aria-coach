# Resume & Interview Coach — Agent Operating Contract

## Mission
Build and audit this repository against the official AI-Powered Resume & Interview Coach problem statement. Optimize for demonstrable problem-statement coverage, technical depth, privacy, reliability, and a compelling end-to-end demo.

## Non-negotiables
1. Do not modify code until you understand the existing architecture and data flow.
2. Trace every PS objective to concrete code, UI, API/tool, model, test, and demo evidence.
3. Never claim "on-device AI" unless the repository contains a real local inference path and the agent can trace user data through it.
4. Never invent an ATS score as if it were an industry-standard ATS score. Label internal scores as a transparent compatibility/match metric and explain what contributes to it.
5. Resume rewriting must never fabricate employers, projects, metrics, dates, skills, or achievements. Ask the system/user to verify unsupported claims.
6. Interview evaluation must prioritize observable evidence: answer content, correctness, structure, relevance, latency, pace, fillers, pauses, clarity, and completeness. Do not infer psychological states from face/voice and present them as facts.
7. Prefer small, testable changes over rewrites. Preserve working behavior.
8. Every meaningful fix must have a verification step: tests, static checks, manual flow, or a reproducible command.
9. Treat resumes, transcripts, job descriptions, and profile data as sensitive user content. Minimize retention, logging, exposure, and third-party transmission.
10. Before declaring success, run the PS compliance auditor and red-team/QA skills.
